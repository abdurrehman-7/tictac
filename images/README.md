# Images Directory

This directory contains all images for the TicTacBags website.

## Directory Structure

- `carousel/` - Hero carousel/banner images
- `products/` - Product images
- `brands/` - Brand logos

## How to Add Images

### For Carousel/Banner Images:
1. Add your banner images to the `carousel/` folder
2. Name them: `banner1.jpg`, `banner2.jpg`, `banner3.jpg`
3. Recommended size: 1200x600 pixels

### For Product Images:
1. Add product images to the `products/` folder  
2. Use descriptive names like: `backpack-leather.jpg`, `handbag-designer.jpg`
3. Recommended size: 500x500 pixels

### For Brand Logos:
1. Add brand logos to the `brands/` folder
2. Use brand names: `tictac-premium.jpg`, `fashion-forward.jpg`
3. Recommended size: 200x100 pixels

## Important Notes:

- All images must be uploaded to GitHub repository to be visible on GitHub Pages
- Use web-optimized formats: JPG, PNG, WebP
- Keep file sizes under 500KB for faster loading
- Use descriptive file names without spaces (use hyphens instead)
